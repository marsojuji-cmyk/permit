# Contributing to Permit

Thanks for your interest in contributing! Here's how to get started.

## Quick Setup

```bash
git clone https://github.com/marsojuji-cmyk/permit
cd permit
python3 -m venv .venv
source .venv/bin/activate
pip install pytest
python demo.py
```

## How to Contribute

### Reporting Bugs

Open an issue using the **Bug Report** template. Include:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Your Python version and OS

### Suggesting Features

Open an issue using the **Feature Request** template. Describe:
- The problem you're trying to solve
- Your proposed solution
- Alternatives you considered

### Submitting Changes

1. Fork the repository
2. Create a branch: `git checkout -b my-feature`
3. Make your changes
4. Run tests: `python -m pytest -q`
5. Push and open a Pull Request

## Code Style

- Python 3.9+ compatible
- Keep demos runnable without credentials
- Every claim in a demo must produce a receipt

## Questions?

Open a Discussion or an Issue. I review everything within 24 hours.
